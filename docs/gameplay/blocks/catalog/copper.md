# Copper and oxidation variants

This catalog contains **125 registered forms**. Names and IDs identify blocks; the last column links related placed-block guides where available. Read each guide’s scope before applying it to a variant.

Names use English localization where available. A † marks a readable registry-name label without a separate English entry; the exact ID is authoritative.
