# Acacia Boat with Chest

## Obtaining

The Acacia Boat with Chest is crafted by combining an Acacia Boat with a Chest. It can also be obtained from the Creative Menu.

## Usage

The Acacia Boat with Chest is used for travel while carrying extra items. Place it, ride it like a normal boat, and open its storage while near it.

## Behavior

It behaves like an Acacia Boat with attached container storage. Breaking it returns the boat-with-chest item and its contents drop.

## Notes

* This item is registered as `minecraft:acacia_chest_boat`.
* The Acacia Boat with Chest appears in the Tools and Utilities creative tab.
