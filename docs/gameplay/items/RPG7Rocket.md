# RPG-7 Rocket

## Obtaining

RPG-7 Rocket can be obtained from the Creative Menu. It is registered as `minecraft:rpg_rocket`.

## Usage

RPG-7 Rocket is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 6 |
| Used by | [RPG-7](RPG7.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
