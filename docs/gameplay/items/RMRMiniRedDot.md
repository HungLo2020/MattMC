# RMR Mini Red Dot

## Obtaining

RMR Mini Red Dot can be obtained from the Creative Menu. It is registered as `minecraft:sight_rmr_dot`.

## Usage

RMR Mini Red Dot is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Scope |
| Attachment level | Not level-based |
| Compatible guns | [B93R](B93R.md), [CZ 75](CZ75.md), [Glock 17](Glock17.md), [M9A4](M9A4.md), [MK23 Offensive Pistol](MK23OffensivePistol.md), [P320](P320.md), [P90 PDW](P90PDW.md), [Timeless .50 Z-Type](Timeless50ZType.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
