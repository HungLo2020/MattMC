# Bucket of Platypus

## Obtaining

Bucket of Platypus is obtained by using a Water Bucket on a Platypus, or from the Creative Menu.

## Usage

Bucket of Platypus is used to carry and release Platypus.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:platypus_bucket`.
