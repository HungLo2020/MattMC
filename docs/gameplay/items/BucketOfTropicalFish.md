# Bucket of Tropical Fish

## Obtaining

Bucket of Tropical Fish is obtained by using a Water Bucket on a Tropical Fish, or from the Creative Menu.

## Usage

Bucket of Tropical Fish is used to carry and release Tropical Fish.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:tropical_fish_bucket`.
