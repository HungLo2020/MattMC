# .30-06 Lonetrail Hand Cannon

Ad Astra.

## Obtaining

.30-06 Lonetrail Hand Cannon can be obtained from the Creative Menu. It is registered as `minecraft:lonetrail`.

## Usage

.30-06 Lonetrail Hand Cannon is a TaCZ firearm. It uses [.30-06 Springfield Bullet](3006SpringfieldBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
