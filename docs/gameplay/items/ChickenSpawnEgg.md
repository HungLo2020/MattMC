# Chicken Spawn Egg

## Obtaining

The Chicken Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Survival as well as Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. [Registration](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/world/item/Items.java#L1820) · [Category entry](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/world/item/CreativeModeTabs.java#L1994)

## Usage

Use the Chicken Spawn Egg on a block to spawn a Chicken.

## Behavior

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Chicken guide](../mobs/Chicken.md).

## Notes

* This item is registered as `minecraft:chicken_spawn_egg`.
