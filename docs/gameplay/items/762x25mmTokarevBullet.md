# 7.62x25mm Tokarev Bullet

## Obtaining

7.62x25mm Tokarev Bullet can be obtained from the Creative Menu. It is registered as `minecraft:762x25`.

## Usage

7.62x25mm Tokarev Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | No integrated guns currently use this ammo |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
