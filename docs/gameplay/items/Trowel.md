# Trowel

## Obtaining

The Crafting Recipe for this item consists of one Iron Ingot and one Stick. 

## Usage

The Trowel is a utility item used to place random blocks from the player's hotbar. To use the Trowel, look at a block face and right click.

When used, the Trowel chooses a valid block from the player's hotbar and attempts to place it against the selected block face. This makes it useful for building with random block variation, such as paths, ruins, walls, floors, terrain detail, and textured builds.

In Survival, placing blocks with the Trowel DOES consume resources from the player's inventory.

## Behavior

The Trowel only places blocks that are available in the player's hotbar. If no valid blocks are available, no block will be placed.

The block placed is chosen randomly from valid hotbar blocks.

The Trowel has NO durability. it is designed purely to help with creative building.

## Notes

* The Trowel is especially useful when building with mixed block palettes.
* The Trowel is best used with several similar blocks in the hotbar, such as stone, cobblestone, andesite, gravel, mossy cobblestone, and cracked stone bricks.

## Trivia

* This item is heavily inspired by and based upon the Trowel item from the Quark mod.
