# Wither Skeleton Spawn Egg

## Obtaining

The Wither Skeleton Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. ## Usage

Use the Wither Skeleton Spawn Egg on a block to spawn a Wither Skeleton.

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Wither Skeleton guide](../mobs/WitherSkeleton.md).
