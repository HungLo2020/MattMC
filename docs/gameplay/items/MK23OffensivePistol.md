# MK23 Offensive Pistol

Under the truck, old friend. An echo of Shadow Moses.

## Obtaining

MK23 Offensive Pistol can be obtained from the Creative Menu. It is registered as `minecraft:hk_mk23`.

## Usage

MK23 Offensive Pistol is a TaCZ firearm. It uses [.45 ACP Bullet](45ACPBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
