# M1014 Battle Shotgun

Dragon's breath rounds are not provided in principle.

## Obtaining

M1014 Battle Shotgun can be obtained from the Creative Menu. It is registered as `minecraft:m1014`.

## Usage

M1014 Battle Shotgun is a TaCZ firearm. It uses [12 Gauge Bullet](12GaugeBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

## Damage Falloff

* 14 blocks: 40
* 28 blocks: 32
* infinite blocks: 24
