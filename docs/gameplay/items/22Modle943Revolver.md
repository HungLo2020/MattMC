# .22 Modle 943 Revolver

Jiu Hu, go slay two monsters for me. Make sure they're alive.

## Obtaining

.22 Modle 943 Revolver can be obtained from the Creative Menu. It is registered as `minecraft:taurus943`.

## Usage

.22 Modle 943 Revolver is a TaCZ firearm. It uses [.22 Winchester Magnum](22WinchesterMagnum.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
