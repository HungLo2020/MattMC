# Knight QD Silencer

## Obtaining

Knight QD Silencer can be obtained from the Creative Menu. It is registered as `minecraft:muzzle_silencer_knight_qd`.

## Usage

Knight QD Silencer is a TaCZ muzzle attachment. Install it through the gun refit screen on compatible firearms.
