# Pewen Sapling

## Obtaining

Pewen Sapling can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Pewen Sapling is used as vegetation, natural decoration, farming, or plant-related building detail.

## Behavior

It can be placed on valid supporting blocks and follows the normal behavior for its plant type.

## Notes

* This item is registered as `minecraft:pewen_sapling`.
* This item comes from bundled prehistoric tree content integrated into MattMC.
