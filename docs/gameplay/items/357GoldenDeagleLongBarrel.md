# .357 Golden Deagle Long Barrel

## Obtaining

.357 Golden Deagle Long Barrel can be obtained from the Creative Menu. It is registered as `minecraft:deagle_golden_long_barrel`.

## Usage

.357 Golden Deagle Long Barrel is a TaCZ muzzle attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Muzzle |
| Attachment level | Not level-based |
| Compatible guns | [Golden Deagle 357](GoldenDeagle357.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
