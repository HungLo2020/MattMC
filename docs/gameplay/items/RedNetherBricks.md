# Red Nether Bricks

**Red Nether Bricks** (`minecraft:red_nether_bricks`) is a separate red masonry block with stair, slab and wall forms. [Registrations][blocks] [items]

## Obtaining and use

Its recipe combines small Nether Brick items with Nether Wart. Follow the [Nether Bricks crafting section](../blocks/NetherBricks.md#crafting-and-cracking) for the arrangement and count. Ordinary Nether Bricks blocks and Nether Wart Blocks are not the named ingredients. [Recipe][crafting-red-nether-bricks]

A placed block drops itself when mined with an **unbroken pickaxe**, including Wood, without needing Silk Touch. Use the [shape and stonecutting tables](../blocks/NetherBricks.md#variants) for the red variants. There is no registered Red Nether Brick Fence or cracked/chiseled red family.
