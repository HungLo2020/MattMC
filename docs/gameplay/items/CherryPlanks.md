# Cherry Planks

## Obtaining

Cherry Planks can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Cherry Planks is a core wood-family building block and crafting ingredient.

## Behavior

It behaves like standard plank construction material and can be used in many wood recipes.

## Notes

* This item is the item form of the `minecraft:cherry_planks` block.
