# AA12 Shotgun

Suffocating barrage of pellets.

## Obtaining

AA12 Shotgun can be obtained from the Creative Menu. It is registered as `minecraft:aa12`.

## Usage

AA12 Shotgun is a TaCZ firearm. It uses [12 Gauge Bullet](12GaugeBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

* 30 blocks: 25
* infinite blocks: 15
