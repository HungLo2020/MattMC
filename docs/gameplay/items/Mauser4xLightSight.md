# Mauser 4x Light Sight

## Obtaining

Mauser 4x Light Sight can be obtained from the Creative Menu. It is registered as `minecraft:scope_98k`.

## Usage

Mauser 4x Light Sight is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Scope |
| Attachment level | Not level-based |
| Compatible guns | [Gewehr 43](Gewehr43.md), [Mauser Kar98k Rifle](MauserKar98kRifle.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
