# Shoebill Spawn Egg

## Obtaining

The Shoebill Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Survival as well as Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. ## Usage

Use the Shoebill Spawn Egg on a block to spawn a Shoebill.
