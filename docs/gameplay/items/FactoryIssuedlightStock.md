# Factory Issued light Stock

## Obtaining

Factory Issued light Stock can be obtained from the Creative Menu. It is registered as `minecraft:oem_stock_light`.

## Usage

Factory Issued light Stock is a TaCZ stock attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Stock |
| Attachment level | Not level-based |
| Compatible guns | [AKM](AKM.md), [HK G3 Battle rifle](HKG3Battlerifle.md), [HK-MP5A5](HKMP5A5.md), [M1 Carbine](M1Carbine.md), [MP40](MP40.md), [RPK](RPK.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
