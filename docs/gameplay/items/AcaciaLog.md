# Acacia Log

## Obtaining

Acacia Logs are gathered from acacia trees or obtained from the Creative Menu.

## Usage

Acacia Logs are used as a building block and as a source of Acacia Planks.

## Behavior

The log has directional placement. Using an axe on it converts it into a Stripped Acacia Log.

## Notes

* This item is the item form of the `minecraft:acacia_log` block.
* It appears in Building Blocks and Natural Blocks.
