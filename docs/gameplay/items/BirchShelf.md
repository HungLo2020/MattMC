# Birch Shelf

## Obtaining

Birch Shelf can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Birch Shelf is a decorative storage block used to display or hold items.

## Behavior

The item registry attaches container data to shelf items, allowing contents to be preserved when represented as an item stack.

## Notes

* This item is the item form of the `minecraft:birch_shelf` block.
