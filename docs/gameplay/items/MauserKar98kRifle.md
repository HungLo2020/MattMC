# Mauser Kar98k Rifle

Did those 98ks lying on the ground back then ever get rusty?

## Obtaining

Mauser Kar98k Rifle can be obtained from the Creative Menu. It is registered as `minecraft:kar98`.

## Usage

Mauser Kar98k Rifle is a TaCZ firearm. It uses [8mm Mauser Bullet](8mmMauserBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

## Damage Falloff

* 40 blocks: 26
* 80 blocks: 22
* infinite blocks: 15

## Attachments

Supported attachment categories: Ammo Modifier, Scope.

* Scope: [Mauser 4x Light Sight](Mauser4xLightSight.md)
* Ammo Modifier: [Full Metal Jacket Ammo](FullMetalJacketAmmo.md), [Hollow-Point Ammo](HollowPointAmmo.md), [Incendiary Ammo](IncendiaryAmmo.md)
