# FN FAL Battle Rifle

The right hand of the free world

## Obtaining

FN FAL Battle Rifle can be obtained from the Creative Menu. It is registered as `minecraft:fn_fal`.

## Usage

FN FAL Battle Rifle is a TaCZ firearm. It uses [.308 Winchester Bullet](308WinchesterBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
