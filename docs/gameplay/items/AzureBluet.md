# Azure Bluet

## Obtaining

Azure Bluets can be found in flower biomes and obtained from the Creative Menu.

## Usage

Azure Bluet is a decorative flower. It can be planted, used in flower pots, or crafted into Light Gray Dye.

## Behavior

It behaves like a small flower and can be placed on valid plant-supporting blocks.

## Notes

* This item is the item form of the `minecraft:azure_bluet` block.
* It appears in the Natural Blocks creative tab.
