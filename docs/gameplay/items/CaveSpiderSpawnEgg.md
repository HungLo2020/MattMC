# Cave Spider Spawn Egg

## Obtaining

The Cave Spider Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. ## Usage

Use the Cave Spider Spawn Egg on a block to spawn a Cave Spider.

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Cave Spider guide](../mobs/CaveSpider.md).
