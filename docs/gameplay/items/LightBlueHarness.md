# Light Blue Harness

## Obtaining

Light Blue Harness can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Light Blue Harness is used as animal equipment where supported by the current build.

## Behavior

Harness items are color variants and behave as equippable utility items for compatible mobs.

## Notes

* This item is registered as `minecraft:light_blue_harness`.
