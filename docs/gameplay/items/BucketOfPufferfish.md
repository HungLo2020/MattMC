# Bucket of Pufferfish

## Obtaining

Bucket of Pufferfish is obtained by using a Water Bucket on a Pufferfish, or from the Creative Menu.

## Usage

Bucket of Pufferfish is used to carry and release Pufferfish.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:pufferfish_bucket`.
