# Lingering Potion

## Obtaining

Lingering Potion can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Lingering Potion is a throwable potion that leaves an effect cloud.

## Behavior

When thrown, it creates a lingering area effect using the potion contents stored on the item.

## Notes

* This item is registered as `minecraft:lingering_potion`.
