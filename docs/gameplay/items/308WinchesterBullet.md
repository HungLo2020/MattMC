# .308 Winchester Bullet

## Obtaining

.308 Winchester Bullet can be obtained from the Creative Menu. It is registered as `minecraft:308`.

## Usage

.308 Winchester Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 48 |
| Used by | [FN EVOLYS Machine Gun](FNEVOLYSMachineGun.md), [FN FAL Battle Rifle](FNFALBattleRifle.md), [HK G3 Battle rifle](HKG3Battlerifle.md), [M134 Minigun](M134Minigun.md), [MK14 EBR](MK14EBR.md), [SCAR-H Battle Rifle](SCARHBattleRifle.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
