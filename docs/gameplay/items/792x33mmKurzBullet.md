# 7.92x33mm Kurz Bullet

## Obtaining

7.92x33mm Kurz Bullet can be obtained from the Creative Menu. It is registered as `minecraft:792x33`.

## Usage

7.92x33mm Kurz Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | [Sturmgewehr 44](Sturmgewehr44.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
