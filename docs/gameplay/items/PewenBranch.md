# Pewen Branch

## Obtaining

Pewen Branch can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Pewen Branch is a wood-family building block or material.

## Behavior

It follows normal wood-family behavior. Axe interactions may strip compatible wood blocks into their stripped form.

## Notes

* This item is registered as `minecraft:pewen_branch`.
* This item comes from bundled prehistoric tree content integrated into MattMC.
