# 6H3 Bayonet

## Obtaining

6H3 Bayonet can be obtained from the Creative Menu. It is registered as `minecraft:bayonet_6h3`.

## Usage

6H3 Bayonet is a TaCZ muzzle attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Muzzle |
| Attachment level | Not level-based |
| Compatible guns | [AKM](AKM.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
