# Bucket of Tadpole

## Obtaining

Bucket of Tadpole is obtained by using a Water Bucket on a Tadpole, or from the Creative Menu.

## Usage

Bucket of Tadpole is used to carry and release Tadpole.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:tadpole_bucket`.
