# World Edit Wand

## Obtaining

No recipe exists for this item as it is purely a creative tool. However it can be obtained in the Creative Menu or by using the command ```//wand```.

## Usage

The World Edit Wand is a utility item used to select two block positions in the world. These positions define a rectangular selection area that can be used by MattMC's built-in world editing tools.

To use the World Edit Wand, look at a block and right click to set the first position. Then look at another block and sneak right click to set the second position.

The selected area is defined by the two chosen corners.

## Behavior

The World Edit Wand does not directly place or break blocks by itself. Instead, it is used to mark a selection area for other world editing commands or tools.

The first selected position and second selected position are stored for the player using the wand. Once both positions are selected, the area between them can be used as the target region for supported world edit operations.

Typical uses include:

* Selecting an area to fill
* Selecting an area to replace blocks
* Selecting an area to clear
* Selecting an area to copy or modify
* Marking a build region for command-based editing

See [Commands](../commands/Commands.md) for more uses.

## Selection

The selected region is a cuboid area between the first and second selected positions.

For example, selecting one corner of a wall and then selecting the opposite corner will define the full rectangular area between those two points.

## Notes

* The World Edit Wand is intended for creative building and development use.
* The item is designed to work with MattMC's built-in world editing features.

## Trivia

* This item is heavily inspired by the wand selection behavior commonly associated with WorldEdit.
* In many WorldEdit-style tools, a wand is used to select two opposite corners of a region before applying editing commands.
