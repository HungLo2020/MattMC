# Franchi Tactical Stock

## Obtaining

Franchi Tactical Stock can be obtained from the Creative Menu. It is registered as `minecraft:stock_tactical_spas_12`.

## Usage

Franchi Tactical Stock is a TaCZ stock attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Stock |
| Attachment level | Not level-based |
| Compatible guns | [SPAS-12 Multi-purpose Shotgun](SPAS12MultipurposeShotgun.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
