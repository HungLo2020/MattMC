# .50 BMG

## Obtaining

.50 BMG can be obtained from the Creative Menu. It is registered as `minecraft:50bmg`.

## Usage

.50 BMG is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 30 |
| Used by | [M107 Sniper Rifle](M107SniperRifle.md), [M95 .50 Cal Antimaterial](M9550CalAntimaterial.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
