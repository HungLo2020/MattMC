# 7.62x39mm Bullet

## Obtaining

7.62x39mm Bullet can be obtained from the Creative Menu. It is registered as `minecraft:762x39`.

## Usage

7.62x39mm Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | [AKM](AKM.md), [RPK](RPK.md), [Sks Tactical Rifle](SksTacticalRifle.md), [Type 81-1 Service Rifle](Type811ServiceRifle.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
