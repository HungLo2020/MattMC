# EXP3 HCOG

## Obtaining

EXP3 HCOG can be obtained from the Creative Menu. It is registered as `minecraft:sight_exp3`.

## Usage

EXP3 HCOG is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.
