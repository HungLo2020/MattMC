# Gewehr 43

One of the first semi-automatic rifles adopted by the German army.

## Obtaining

Gewehr 43 can be obtained from the Creative Menu. It is registered as `minecraft:g43`.

## Usage

Gewehr 43 is a TaCZ firearm. It uses [8mm Mauser Bullet](8mmMauserBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
