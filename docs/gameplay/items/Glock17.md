# Glock 17

Exercise your Second Amendment rights.

## Obtaining

Glock 17 can be obtained from the Creative Menu. It is registered as `minecraft:glock_17`.

## Usage

Glock 17 is a TaCZ firearm. It uses [9mm Bullet](9mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
