# Netherite Helmet

## Obtaining

Netherite Helmet can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Netherite Helmet is wearable netherite armor.

## Behavior

It provides armor protection when equipped and has the durability and fire-resistant behavior associated with netherite gear.

## Notes

* This item is registered as `minecraft:netherite_helmet`.
