# Bucket of Blobfish

## Obtaining

Bucket of Blobfish is obtained by using a Water Bucket on a Blobfish, or from the Creative Menu.

## Usage

Bucket of Blobfish is used to carry and release Blobfish.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:blobfish_bucket`.
