# Goat Horn

A Goat Horn (`minecraft:goat_horn`) is an **unstackable, reusable instrument**. Its stored instrument selects its sound. Playing it is a use action with a cooldown, not a durability or ingredient cost. [Registration][horn-reg] · [Instrument use][horn-use]

## Obtaining

A [Goat](../mobs/Goat.md#ramming-and-horn-collection) can lose one remaining horn during a ram that reaches a block in the horn-snapping tag. An ordinary animal collision ends the ram first; killing a Goat does not grant a horn from its death table. The checked snapping blocks are: [Ram branches][ram-hit] · [Remaining-horn drop][goat-horns] · [Goat death loot][goat-loot]

| Group | Eligible blocks in the bundled tag |
| --- | --- |
| Logs | Unstripped Acacia, Birch, Oak, Jungle, Spruce, Dark Oak, Pale Oak, Mangrove and Cherry Logs |
| Other blocks | Stone, Packed Ice, Iron Ore, Coal Ore, Copper Ore and Emerald Ore |

[Snapping tag][ram-blocks] · [Nested natural-log tag][logs]

This does not include every wood-looking block or every ore variant. Use the Goat guide for run-up, target and ram conditions; simply pushing a Goat against Stone is not the checked collection trigger.

Ordinary Goats choose from **Ponder, Sing, Seek and Feel**. Screaming Goats choose **Admire, Call, Yearn and Dream**. The choice is seeded from the Goat's UUID, so its two horns normally have the same instrument when the tag data and screaming state stay unchanged. Adult feeding does not regrow lost horns; kids receive horns when they grow up. [Instrument choice][goat-horn-choice] · [Regular choices][regular-horns] · [Screaming choices][screaming-horns] · [Age/horn transition][goat-health]

A [Pillager Outpost chest](../structures/PillagerOutpost.md#chest-rewards) is another checked source, using the regular horn pool. The ordinary category list also generates all eight tagged horn variants for the [inventory item browser](../mechanics/InventoryBrowser.md), visible in Survival and Creative; insertion requires Creative. These are separate loot and insertion routes. [Category generation][horn-entry] [Variant entries][horn-variants] · [Combined horn tag][all-horns]

## Usage

Hold the Horn and use it to play its stored instrument. All eight bundled instruments define a **7-second use duration**, and the item converts that to a **140-tick cooldown** at the normal 20 ticks/second. Sound starts when use begins; the item emits an instrument-play game event. [Use and duration conversion][horn-use] · [Ponder][horn-ponder] · [Sing][horn-sing] · [Seek][horn-seek] · [Feel][horn-feel] · [Admire][horn-admire] · [Call][horn-call] · [Yearn][horn-yearn] · [Dream][horn-dream]

The ordinary cooldown group is the item ID, so swapping to another Goat Horn sound does not bypass the same player's active horn cooldown. The server checks that cooldown before invoking item use. [Cooldown grouping][horn-cooldown] · [Use gate][horn-use-gate]

## Behavior

The registered default instrument is **Ponder**; horns generated by the Goat and category-list paths attach their selected instrument component. Playing the horn does not itself run the Goat's ram AI, summon a raid or change the animal's variant. [Default component][horn-reg] · [Selected component and playback][horn-use]
