# Ender Dragon Spawn Egg

## Obtaining

The Ender Dragon Spawn Egg is registered but absent from the checked category list, so it does not appear in the ordinary inventory browser. A player with permission level **2** can obtain it with `/give @s minecraft:ender_dragon_spawn_egg`. See [Spawn eggs](SpawnEggs.md#obtaining) for the checked access rules. ## Usage

Use the Ender Dragon Spawn Egg on a block to spawn an Ender Dragon.

## Behavior

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Ender Dragon guide](../mobs/EnderDragon.md).
