# Red Stained Glass

## Obtaining

Red Stained Glass can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Red Stained Glass is a transparent colored building block.

## Behavior

It behaves like glass and lets light pass through while tinting the build visually.

## Notes

* This item is the item form of the `minecraft:red_stained_glass` block.
