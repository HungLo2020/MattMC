# Bucket of Axolotl

## Obtaining

Bucket of Axolotl is obtained by using a Water Bucket on an Axolotl, or from the Creative Menu.

## Usage

Bucket of Axolotl is used to carry and release Axolotl.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:axolotl_bucket`.
