# Gold Ingot

## Obtaining

Gold Ingot can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Offer Gold Ingots to an eligible adult [Piglin](../mobs/Piglin.md#bartering) for a random barter result. See that guide for valid offers, interruptions and the bundled reward table.

Gold Ingot is used as a crafting ingredient, utility item, or interaction item depending on the recipe and gameplay system.

## Behavior

It is a stackable item unless its item properties define a different stack limit or use behavior.

## Notes

* This item is registered as `minecraft:gold_ingot`.
