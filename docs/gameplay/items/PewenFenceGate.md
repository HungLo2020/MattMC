# Pewen Fence Gate

## Obtaining

Pewen Fence Gate can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Pewen Fence Gate is used as an openable passage in fences and walls.

## Behavior

It can be opened by hand or redstone. When closed, it blocks movement; when open, entities can pass through.

## Notes

* This item is registered as `minecraft:pewen_fence_gate`.
