# sight_p90

## Obtaining

sight_p90 can be obtained from the Creative Menu. It is registered as `minecraft:sight_p90`.

## Usage

sight_p90 is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Scope |
| Attachment level | Not level-based |
| Compatible guns | [P90 PDW](P90PDW.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
