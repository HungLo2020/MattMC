# Bucket of Mudskipper

## Obtaining

Bucket of Mudskipper is obtained by using a Water Bucket on a Mudskipper, or from the Creative Menu.

## Usage

Bucket of Mudskipper is used to carry and release Mudskipper.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:mudskipper_bucket`.
