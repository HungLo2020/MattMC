# Building  Wand 

## Obtaining
Currently no recipe exists for this item in survival however it can be obtained through the creative menu.

## Usage
The building wand can place or break up to 256 blocks at a time in a single plane. to place blocks look at a block face and right click. to break blocks sneak right click. The block placed always matches the block of the block face you are looking at.

In Survival, breaking blocks with the Building Wand yields no droppable resources. In survival placing blocks with the wand DOES consume resources.
