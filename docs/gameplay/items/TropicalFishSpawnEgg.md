# Tropical Fish Spawn Egg

## Obtaining

The Tropical Fish Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. ## Usage

Use the Tropical Fish Spawn Egg on a block to spawn a Tropical Fish.

## Behavior

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Tropical Fish guide](../mobs/TropicalFish.md).
