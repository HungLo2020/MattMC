# Bamboo Fence Gate

## Obtaining

Bamboo Fence Gate can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Bamboo Fence Gate is used as an openable passage in fences and walls.

## Behavior

It can be opened by hand or redstone. When closed, it blocks movement; when open, entities can pass through.

## Notes

* This item is the item form of the `minecraft:bamboo_fence_gate` block.
