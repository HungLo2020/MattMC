# M9 Bayonet

## Obtaining

M9 Bayonet can be obtained from the Creative Menu. It is registered as `minecraft:bayonet_m9`.

## Usage

M9 Bayonet is a TaCZ muzzle attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Muzzle |
| Attachment level | Not level-based |
| Compatible guns | [AUG](AUG.md), [M16A1 Service Rifle](M16A1ServiceRifle.md), [M16A4 Service Rifle](M16A4ServiceRifle.md), [M4A1 Carbine](M4A1Carbine.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
