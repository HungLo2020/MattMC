# Light Gray Stained Glass

## Obtaining

Light Gray Stained Glass can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Light Gray Stained Glass is a transparent colored building block.

## Behavior

It behaves like glass and lets light pass through while tinting the build visually.

## Notes

* This item is the item form of the `minecraft:light_gray_stained_glass` block.
