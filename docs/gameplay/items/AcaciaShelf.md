# Acacia Shelf

## Obtaining

Acacia Shelves can be obtained from the Creative Menu and by using their registered recipe if enabled in the current build.

## Usage

The Acacia Shelf is a decorative storage block used to display or hold items.

## Behavior

The item registry attaches container data to the shelf item, allowing it to preserve shelf contents when represented as an item stack.

## Notes

* This item is the item form of the `minecraft:acacia_shelf` block.
* It appears in the Functional Blocks creative tab.
