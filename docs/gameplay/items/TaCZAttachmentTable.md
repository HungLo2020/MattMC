# TaCZ Attachment Table

## Obtaining

TaCZ Attachment Table can be crafted and can also be obtained from the Creative Menu. It is registered as `minecraft:attachment_workbench`.

## Usage

TaCZ Attachment Table is used to craft firearm attachments from the integrated TaCZ and gun pack recipe set. Place it and open it to browse craftable attachments.

## Behavior

The table shows every registered attachment recipe and consumes the listed materials from the player inventory when an attachment is crafted.

## Notes

* This item is the item form of the `minecraft:attachment_workbench` block.
* This block is part of the integrated TaCZ firearms system.
