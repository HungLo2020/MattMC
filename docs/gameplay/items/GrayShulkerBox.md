# Gray Shulker Box

## Obtaining

Gray Shulker Box can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Gray Shulker Box is portable container storage.

## Behavior

It keeps its inventory when broken and can be placed again later with the contents intact.

## Notes

* This item is the item form of the `minecraft:gray_shulker_box` block.
