# .45-70 Bullet

## Obtaining

.45-70 Bullet can be obtained from the Creative Menu. It is registered as `minecraft:45_70`.

## Usage

.45-70 Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 48 |
| Used by | [Springfield 1873 Trapdoor Rifle](Springfield1873TrapdoorRifle.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
