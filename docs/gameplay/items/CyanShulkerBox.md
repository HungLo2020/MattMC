# Cyan Shulker Box

## Obtaining

Cyan Shulker Box can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Cyan Shulker Box is portable container storage.

## Behavior

It keeps its inventory when broken and can be placed again later with the contents intact.

## Notes

* This item is the item form of the `minecraft:cyan_shulker_box` block.
