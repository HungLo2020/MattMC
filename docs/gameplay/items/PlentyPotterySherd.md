# Plenty Pottery Sherd

The **Plenty Pottery Sherd** (`minecraft:plenty_pottery_sherd`) adds the **plenty pattern** to one face of a [Decorated Pot](../blocks/DecoratedPot.md). Find it by brushing generated Suspicious Gravel at **cold [Ocean Ruins](../structures/OceanRuins.md#archaeology)**. [Item registration][registration] · [Pattern mapping][pattern] · [Archaeology table][loot]

## Obtaining

Use a serviceable [Brush](Brush.md#archaeology-basics) on **[Suspicious Gravel](SuspiciousGravel.md)** generated by a cold ocean ruin. The generator converts selected template Gravel to suspicious blocks and assigns the cold-ruin archaeology table. The [Ocean Ruins search guide](../structures/OceanRuins.md#where-to-search) lists the eligible biomes. [Assigned table][processors] · [Placement settings][assembly]

Each block using the unchanged `minecraft:archaeology/ocean_ruin_cold` table makes **one weighted roll**. Plenty has weight **1 out of 15**, so the chance is **1/15 (about 6.67%)**, yielding **one sherd** if selected. This is a chance per assigned archaeology block, not per ruin or chest. The warm-ruin archaeology table does not contain this sherd. [Loot][loot] · [Other ruin table][other-loot] · [Default weight][weights] · [Weighted roll][roll]

A ruin does not promise a sherd or a fixed number of suspicious blocks. The replacement cap applies per template-processing pass, and final placement depends on the template and terrain; cold ruins also overlay multiple templates. See the [shared archaeology guide](../structures/OceanRuins.md#archaeology). [Replacement cap][cap] · [Ruin assembly][assembly]

## Usage

Use this sherd in the [Decorated Pot recipe](../blocks/DecoratedPot.md#crafting-and-choosing-faces), alongside accepted sherds and/or loose [Bricks](Brick.md). Each Plenty sherd supplies one plenty face; four matching faces require four Plenty sherds. The recipe's top, bottom, left and right ingredients select the back, front, left and right faces respectively. [Recipe][recipe] · [Accepted ingredients][ingredients] · [Sherd membership][sherds] · [Pattern mapping][pattern]

Using a sherd on a placed pot attempts to insert it into storage; it does not change a face. Follow the [pot interaction guide](../blocks/DecoratedPot.md#storage-and-player-interaction) for storage and retrieval. [Placed use][insert]

## Behavior

Brush **in place with the support intact**, including underwater. Keep enough air and a safe route to the surface; the [Ocean Ruins preparation guide](../structures/OceanRuins.md#hazards-and-preparation) covers the hazards. Water does not block the Brush's targeting, but removing support can make the suspicious block fall and lose its archaeology contents. Ordinary mining, including Silk Touch, is not a collection method; see [suspicious terrain handling](../blocks/SoilSandAndGravel.md#suspicious-sand-and-suspicious-gravel). [Brush targeting][brush] · [Fluid targeting][underwater] · [Falling behavior][falling] · [Block loot][block-loot]

The assigned loot is resolved on the first successful brush pulse and then retained. Stopping and restarting can lose brushing progress, but does **not** reroll the stored item. Completion releases it once and changes the block to ordinary Gravel; brushing that result does not yield another artifact. Use the [Brush guide](Brush.md#archaeology-basics) for timing, and replace or repair a fully worn Brush before starting another block. [Stored loot and completion][brush-loot] · [Broken-Brush guard][broken-brush]

To reuse a sherd already decorating a pot, follow [pot ingredient recovery](../blocks/DecoratedPot.md#breaking-keep-the-pot-or-recover-ingredients). In ordinary Survival breaking, a tagged breaking tool without Silk Touch shatters the pot and returns one ingredient for each face. Breaking by hand, or using a protecting enchantment, keeps the decorated pot instead. This recovers existing face ingredients; it does not multiply them. [Break selection][recovery] · [Breaking tools][break-tools] · [Protection tag][silk] · [Pot loot][pot-loot]
