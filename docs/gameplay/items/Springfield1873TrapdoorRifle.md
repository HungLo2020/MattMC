# Springfield 1873 Trapdoor Rifle

Poverty shrinks not the gun.

## Obtaining

Springfield 1873 Trapdoor Rifle can be obtained from the Creative Menu. It is registered as `minecraft:springfield1873`.

## Usage

Springfield 1873 Trapdoor Rifle is a TaCZ firearm. It uses [.45-70 Bullet](4570Bullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
