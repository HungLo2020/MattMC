# QBZ-95 "Longbow"

What was your mission in Shanghai!

## Obtaining

QBZ-95 "Longbow" can be obtained from the Creative Menu. It is registered as `minecraft:qbz_95`.

## Usage

QBZ-95 "Longbow" is a TaCZ firearm. It uses [5.8mm DBP87 Bullet](58mmDBP87Bullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
