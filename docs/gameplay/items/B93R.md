# B93R

Bureaucratic lie again? Maybe not.

## Obtaining

B93R can be obtained from the Creative Menu. It is registered as `minecraft:b93r`.

## Usage

B93R is a TaCZ firearm. It uses [9mm Bullet](9mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

## Damage Falloff

* 16 blocks: 7.5
* 32 blocks: 6
* 48 blocks: 4
* infinite blocks: 3
