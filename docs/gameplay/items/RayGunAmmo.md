# Ray Gun Ammo

## Obtaining

Ray Gun Ammo can be obtained from the Creative Menu. It is registered as `minecraft:raygun_ammo`.

## Usage

Ray Gun Ammo is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 64 |
| Used by | [Ray Gun](RayGun.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
