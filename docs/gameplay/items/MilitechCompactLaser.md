# Militech Compact Laser

## Obtaining

Militech Compact Laser can be obtained from the Creative Menu. It is registered as `minecraft:laser_compact`.

## Usage

Militech Compact Laser is a TaCZ laser attachment. Install it through the gun refit screen on compatible firearms.
