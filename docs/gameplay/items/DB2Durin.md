# DB-2 Durin

Although it's not the right size, it gets the job done.

## Obtaining

DB-2 Durin can be obtained from the Creative Menu. It is registered as `minecraft:db_short`.

## Usage

DB-2 Durin is a TaCZ firearm. It uses [12 Gauge Bullet](12GaugeBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
