# P320

Better throw it away, you can destroy them by firewalking.

## Obtaining

P320 can be obtained from the Creative Menu. It is registered as `minecraft:p320`.

## Usage

P320 is a TaCZ firearm. It uses [.45 ACP Bullet](45ACPBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

## Damage Falloff

* 20 blocks: 10
* 50 blocks: 7
* infinite blocks: 5
