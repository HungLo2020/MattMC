# 40mm Grenade

## Obtaining

40mm Grenade can be obtained from the Creative Menu. It is registered as `minecraft:40mm`.

## Usage

40mm Grenade is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 6 |
| Used by | [M320 Grenade Launcher](M320GrenadeLauncher.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
