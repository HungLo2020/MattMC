# Shelter Pottery Sherd

## Obtaining

Shelter Pottery Sherd is found through archaeology sources or obtained from the Creative Menu.

## Usage

Shelter Pottery Sherd is used to decorate a Decorated Pot with the shelter pattern.

## Behavior

Pottery sherds are crafting ingredients. When used in a Decorated Pot recipe, the sherd determines the pattern on one side of the pot.

## Notes

* This item is registered as `minecraft:shelter_pottery_sherd`.
