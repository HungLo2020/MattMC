# .357 Magnum

## Obtaining

.357 Magnum can be obtained from the Creative Menu. It is registered as `minecraft:357mag`.

## Usage

.357 Magnum is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 48 |
| Used by | [.357 Rhino Revolver](357RhinoRevolver.md), [Golden Deagle 357](GoldenDeagle357.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
