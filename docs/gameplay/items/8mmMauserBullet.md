# 8mm Mauser Bullet

## Obtaining

8mm Mauser Bullet can be obtained from the Creative Menu. It is registered as `minecraft:792x57`.

## Usage

8mm Mauser Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 36 |
| Used by | [Gewehr 43](Gewehr43.md), [Mauser Kar98k Rifle](MauserKar98kRifle.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
