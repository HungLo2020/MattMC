# Footprint Pottery Sherd

## Obtaining

Footprint Pottery Sherd is found through archaeology sources or obtained from the Creative Menu.

## Usage

Footprint Pottery Sherd is used to decorate a Decorated Pot with the footprint pattern.

## Behavior

Pottery sherds are crafting ingredients. When used in a Decorated Pot recipe, the sherd determines the pattern on one side of the pot.

## Notes

* This item is registered as `minecraft:footprint_pottery_sherd`.
