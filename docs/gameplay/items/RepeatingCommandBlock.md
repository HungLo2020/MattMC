# Repeating Command Block

## Obtaining

Registered in operator contents for Creative instant-build plus permission level 2. No bundled recipe or mining-drop route. See [the inventory browser](../mechanics/InventoryBrowser.md) for its current access rules. [Item registry][items]

## Usage

Repeats a stored command on scheduled game ticks while powered or Always Active. Use [Command Blocks](../blocks/CommandBlocks.md#repeating-command-block) for the canonical placed-block instructions and their source evidence.

## Behavior

Game Master placement, editor, and removal gates apply. The commandBlocksEnabled gamerule also gates editing/execution; this is not a crafted Survival clock.
