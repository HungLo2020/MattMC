# Bucket of Large Catfish

## Obtaining

Bucket of Large Catfish is obtained by using a Water Bucket on a Large Catfish, or from the Creative Menu.

## Usage

Bucket of Large Catfish is used to carry and release Large Catfish.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:large_catfish_bucket`.
