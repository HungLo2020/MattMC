# Sturmgewehr 44

The first assault rifle.

## Obtaining

Sturmgewehr 44 can be obtained from the Creative Menu. It is registered as `minecraft:stg44`.

## Usage

Sturmgewehr 44 is a TaCZ firearm. It uses [7.92x33mm Kurz Bullet](792x33mmKurzBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
