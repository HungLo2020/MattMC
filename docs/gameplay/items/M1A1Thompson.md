# M1A1 Thompson

A later model of the improved M1 that aimed for cheap manufacture.

## Obtaining

M1A1 Thompson can be obtained from the Creative Menu. It is registered as `minecraft:m1a1`.

## Usage

M1A1 Thompson is a TaCZ firearm. It uses [.45 ACP Bullet](45ACPBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
