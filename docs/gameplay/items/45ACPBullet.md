# .45 ACP Bullet

## Obtaining

.45 ACP Bullet can be obtained from the Creative Menu. It is registered as `minecraft:45acp`.

## Usage

.45 ACP Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | [M1911](M1911.md), [M1A1 Thompson](M1A1Thompson.md), [MK23 Offensive Pistol](MK23OffensivePistol.md), [P320](P320.md), [UMP45 SMG](UMP45SMG.md), [Vector SMG](VectorSMG.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
