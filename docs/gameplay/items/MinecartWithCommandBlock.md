# Minecart with Command Block

## Obtaining

Minecart with Command Block can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Minecart with Command Block is used for rail transportation or minecart-based utility systems.

## Behavior

Minecart variants move on rails and provide their configured storage, redstone, explosive, or utility behavior.

## Notes

* This item is registered as `minecraft:command_block_minecart`.
