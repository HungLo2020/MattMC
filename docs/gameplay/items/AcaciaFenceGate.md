# Acacia Fence Gate

## Obtaining

Acacia Fence Gates are crafted from Acacia Planks and Sticks. They can also be obtained from the Creative Menu.

## Usage

The Acacia Fence Gate is used as an openable passage in fences and walls.

## Behavior

It can be opened by hand or redstone. When closed, it blocks movement like a fence; when open, entities can pass through.

## Notes

* This item is the item form of the `minecraft:acacia_fence_gate` block.
* It appears with other acacia building blocks in the Building Blocks creative tab.
