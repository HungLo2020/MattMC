# Chain Command Block

## Obtaining

Registered in operator contents for Creative instant-build plus permission level 2. No bundled recipe or mining-drop route. See [the inventory browser](../mechanics/InventoryBrowser.md) for its current access rules. [Item registry][items]

## Usage

Runs when reached by an executing command-block chain, following facing and condition controls. Use [Command Blocks](../blocks/CommandBlocks.md#chain-command-block) for the canonical placed-block instructions and their source evidence.

## Behavior

Game Master gates and commandBlocksEnabled apply. A redstone input alone does not start the chain; new plain Chain blocks are automatic.
