# .357 Rhino Revolver

Maybe you don't want to mess with this rhino.

## Obtaining

.357 Rhino Revolver can be obtained from the Creative Menu. It is registered as `minecraft:rhino357`.

## Usage

.357 Rhino Revolver is a TaCZ firearm. It uses [.357 Magnum](357Magnum.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

* 25 blocks: 10.5

* 50 blocks: 6
