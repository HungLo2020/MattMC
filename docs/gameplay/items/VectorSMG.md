# Vector SMG

It is fast, but a bit too fast.

## Obtaining

Vector SMG can be obtained from the Creative Menu. It is registered as `minecraft:vector45`.

## Usage

Vector SMG is a TaCZ firearm. It uses [.45 ACP Bullet](45ACPBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

| Property | Value |

| Ammo | [.45 ACP Bullet](45ACPBullet.md) |
| Magazine size | 20 |

## Accuracy

| Property | Value |
| --- | --- |
| Standing | 3.5 |
| Moving | 4.5 |
| Sneaking | 2 |
| Prone | 1 |

## Damage Falloff

* 15 blocks: 7
* 36 blocks: 5.5
* 50 blocks: 4.5
* infinite blocks: 3.5
