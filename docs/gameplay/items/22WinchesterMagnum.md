# .22 Winchester Magnum

## Obtaining

.22 Winchester Magnum can be obtained from the Creative Menu. It is registered as `minecraft:22wmr`.

## Usage

.22 Winchester Magnum is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 64 |
| Used by | [.22 Modle 943 Revolver](22Modle943Revolver.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
