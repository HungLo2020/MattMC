# LPVO 1-6x Scope

## Obtaining

LPVO 1-6x Scope can be obtained from the Creative Menu. It is registered as `minecraft:scope_lpvo_1_6`.

## Usage

LPVO 1-6x Scope is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.
