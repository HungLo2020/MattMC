# Calcite

**Calcite** (`minecraft:calcite`) is a pale, placeable building block. It has no registered polished, brick, chiseled, stair, slab or wall variants. [Registrations][blocks] [items]

## Obtaining and use

Gather Calcite from the checked **Amethyst Geode shell** or **Stony Peaks surface** routes, explained in the [Calcite block section](../blocks/DecorativeStone.md#calcite). Use an **unbroken pickaxe**, including Wood, to receive one Calcite from the placed block. Silk Touch is unnecessary and Fortune does not multiply the drop. [Geode configuration][geode-config] · [Surface settings][overworld] · [Loot][loot-calcite] · [Mining tag][pickaxe]

The bundled scan found no crafting, smelting or stonecutting recipe producing Calcite, nor a recipe using it as a named ingredient. Place it as a full block using the [documented block behavior](../blocks/DecorativeStone.md#placement-and-properties). It is also listed in the Natural Blocks Creative tab. [Creative entry][creative]
