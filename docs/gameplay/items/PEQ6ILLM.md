# PEQ6 ILLM

## Obtaining

PEQ6 ILLM can be obtained from the Creative Menu. It is registered as `minecraft:laser_peq6`.

## Usage

PEQ6 ILLM is a TaCZ laser attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Laser |
| Attachment level | Not level-based |
| Compatible guns | [MK23 Offensive Pistol](MK23OffensivePistol.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
