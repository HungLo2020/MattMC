# Arms Up Pottery Sherd

## Obtaining

Arms Up Pottery Sherds are found through archaeology sources or obtained from the Creative Menu.

## Usage

The Arms Up Pottery Sherd is used to decorate a Decorated Pot with the arms up pattern.

## Behavior

Pottery sherds are crafting ingredients. When used in a Decorated Pot recipe, the sherd determines the pattern on one side of the pot.

## Notes

* This item is registered as `minecraft:arms_up_pottery_sherd`.
* It appears in the Ingredients creative tab.
