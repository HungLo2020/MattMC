# M870

You pick the wrong house, Fool!

## Obtaining

M870 can be obtained from the Creative Menu. It is registered as `minecraft:m870`.

## Usage

M870 is a TaCZ firearm. It uses [12 Gauge Bullet](12GaugeBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

## Damage Falloff

* 18 blocks: 36
* 32 blocks: 27
* infinite blocks: 18
