# Jigsaw Block

## Obtaining

Registered in operator contents for Creative instant-build plus permission level 2. No bundled recipe or mining-drop route. See [the inventory browser](../mechanics/InventoryBrowser.md) for its current access rules. [Item registry][items]

## Usage

Connects pieces from configured template pools. A pool ID, target name, orientation, and compatible templates are required for useful generation. Use [Structure and Jigsaw Blocks](../blocks/StructureAndJigsawBlocks.md#jigsaw-block) for the canonical placed-block instructions and their source evidence.

## Behavior

Game Master placement, editor, and removal gates apply. It does not generate an arbitrary building merely from being placed.
