# AUG

It's a nice thing to carry, isn't it?

## Obtaining

AUG can be obtained from the Creative Menu. It is registered as `minecraft:aug`.

## Usage

AUG is a TaCZ firearm. It uses [5.56x45mm Bullet](556x45mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

* 28 blocks: 7
* 65 blocks: 6
* infinite blocks: 5
