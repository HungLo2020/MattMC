# Friend Pottery Sherd

## Obtaining

Friend Pottery Sherd is found through archaeology sources or obtained from the Creative Menu.

## Usage

Friend Pottery Sherd is used to decorate a Decorated Pot with the friend pattern.

## Behavior

Pottery sherds are crafting ingredients. When used in a Decorated Pot recipe, the sherd determines the pattern on one side of the pot.

## Notes

* This item is registered as `minecraft:friend_pottery_sherd`.
