# M134 Minigun

"Burn me to the ground"

## Obtaining

M134 Minigun can be obtained from the Creative Menu. It is registered as `minecraft:minigun`.

## Usage

M134 Minigun is a TaCZ firearm. It uses [.308 Winchester Bullet](308WinchesterBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
