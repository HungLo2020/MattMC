# Vulture .50 Cal Suppressor

## Obtaining

Vulture .50 Cal Suppressor can be obtained from the Creative Menu. It is registered as `minecraft:muzzle_silencer_vulture`.

## Usage

Vulture .50 Cal Suppressor is a TaCZ muzzle attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Muzzle |
| Attachment level | Not level-based |
| Compatible guns | [M107 Sniper Rifle](M107SniperRifle.md), [M95 .50 Cal Antimaterial](M9550CalAntimaterial.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
