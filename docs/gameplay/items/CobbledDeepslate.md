# Cobbled Deepslate

**Cobbled Deepslate** (`minecraft:cobbled_deepslate`) is the main starting material for dark stone construction. [Item registration][items]

## Obtaining and use

Mine ordinary Deepslate with an **unbroken pickaxe without Silk Touch**, or mine an existing Cobbled Deepslate block with a pickaxe. Cobbled Deepslate itself does not need Silk Touch to be recovered. [Deepslate loot][loot-deepslate] · [Cobbled loot][loot-cobbled-deepslate] · [Mining tag][pickaxe]

Use the [Deepslate guide](../blocks/Deepslate.md#crafting-and-smelting) for polished blocks, bricks, tiles, chiseled blocks and their shapes. The [Stonecutter shortcuts](../blocks/Deepslate.md#stonecutting-shortcuts) can skip intermediate finishes. Smelting it returns ordinary Deepslate. [Polishing][crafting-polished-deepslate] · [Direct tile cut][stonecutting-deepslate-tiles-from-cobbled-deepslate-stonecutting] · [Smelting][smelting-deepslate]

It also works in the checked [Furnace](../blocks/Furnace.md#crafting-and-mining) and [Stone Pickaxe](StonePickaxe.md) recipes through their material tags. This does not make it interchangeable with Cobblestone in every recipe. [Material tags][stone-materials] [tool-materials]
