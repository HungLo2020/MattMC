# Rifle Ammo

## Obtaining

Rifle Ammo can be obtained from the Creative Menu. It is registered as `minecraft:rifles_ammo`.

## Usage

Rifle Ammo is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 64 |
| Used by | No integrated guns currently use this ammo |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
