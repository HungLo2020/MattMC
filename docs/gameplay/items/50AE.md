# .50 AE

## Obtaining

.50 AE can be obtained from the Creative Menu. It is registered as `minecraft:50ae`.

## Usage

.50 AE is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 48 |
| Used by | [Deagle 50](Deagle50.md), [Timeless .50 Z-Type](Timeless50ZType.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
