# .30 Carbine Bullet

## Obtaining

.30 Carbine Bullet can be obtained from the Creative Menu. It is registered as `minecraft:30c`.

## Usage

.30 Carbine Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 50 |
| Used by | [M1 Carbine](M1Carbine.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
