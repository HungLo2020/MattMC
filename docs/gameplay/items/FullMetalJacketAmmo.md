# Full Metal Jacket Ammo

## Obtaining

Full Metal Jacket Ammo can be obtained from the Creative Menu. It is registered as `minecraft:ammo_mod_fmj`.

## Usage

Full Metal Jacket Ammo is a TaCZ ammo modifier attachment. Install it through the gun refit screen on compatible firearms.
