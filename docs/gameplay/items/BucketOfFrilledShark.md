# Bucket of Frilled Shark

## Obtaining

Bucket of Frilled Shark is obtained by using a Water Bucket on a Frilled Shark, or from the Creative Menu.

## Usage

Bucket of Frilled Shark is used to carry and release Frilled Shark.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:frilled_shark_bucket`.
