# Light

## Obtaining

Registered in permission-gated operator contents with all 16 light levels. The ordinary item defaults to level 15. No bundled recipe. See [the inventory browser](../mechanics/InventoryBrowser.md) for its current access rules. [Item registry][items]

## Usage

Places invisible, noncolliding light. Read the guide for targeting, level cycling, waterlogging, and marker visibility. Use [Light](../blocks/TechnicalBlocks.md#light) for the canonical placed-block instructions and their source evidence.

## Behavior

The supplied ordinary block item has no Game Master placement gate; cycling the placed level requires Creative instant-build and permission level 2. No ordinary drops.
