# M320 Grenade Launcher

Count to three, you still have a chance to run... Three!

## Obtaining

M320 Grenade Launcher can be obtained from the Creative Menu. It is registered as `minecraft:m320`.

## Usage

M320 Grenade Launcher is a TaCZ firearm. It uses [40mm Grenade](40mmGrenade.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
