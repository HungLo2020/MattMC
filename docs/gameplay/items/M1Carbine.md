# M1 Carbine

A carbine that was given to soldiers during World War 2 to supplement the M1 Garand.

## Obtaining

M1 Carbine can be obtained from the Creative Menu. It is registered as `minecraft:m1`.

## Usage

M1 Carbine is a TaCZ firearm. It uses [.30 Carbine Bullet](30CarbineBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
