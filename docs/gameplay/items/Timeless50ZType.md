# Timeless .50 Z-Type

Let it all start from zero again. TaCZ 1st Anniversary

## Obtaining

Timeless .50 Z-Type can be obtained from the Creative Menu. It is registered as `minecraft:timeless50`.

## Usage

Timeless .50 Z-Type is a TaCZ firearm. It uses [.50 AE](50AE.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
