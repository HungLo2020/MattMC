# 5.7x28mm AP Bullet

## Obtaining

5.7x28mm AP Bullet can be obtained from the Creative Menu. It is registered as `minecraft:57x28`.

## Usage

5.7x28mm AP Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | [P90 PDW](P90PDW.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
