# Vintage Springfield Scope

## Obtaining

Vintage Springfield Scope can be obtained from the Creative Menu. It is registered as `minecraft:scope_1873_6x`.

## Usage

Vintage Springfield Scope is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Scope |
| Attachment level | Not level-based |
| Compatible guns | [Springfield 1873 Trapdoor Rifle](Springfield1873TrapdoorRifle.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
