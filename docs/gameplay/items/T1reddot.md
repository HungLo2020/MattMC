# T1 red dot

## Obtaining

T1 red dot can be obtained from the Creative Menu. It is registered as `minecraft:sight_t1`.

## Usage

T1 red dot is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Scope |
| Attachment level | Not level-based |
| Compatible guns | [Deagle 50](Deagle50.md), [Golden Deagle 357](GoldenDeagle357.md), [Taurus "Raging Hunter" Hand Cannon](TaurusRagingHunterHandCannon.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
