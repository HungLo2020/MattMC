# Clay Ball

A **Clay Ball** (`minecraft:clay_ball`) is an ingredient for Clay blocks and loose Bricks. It is an ordinary item, not a block you can place directly. [Registration][ingredients]

## Obtaining and use

Ordinary mining of **one Clay block without Silk Touch** yields **four Clay Balls**. Fortune has no multiplier in that loot table. Silk Touch returns the Clay block instead, and explosions can reduce the ball yield. [Clay loot][clay-loot]

Use the [Clay and Bricks recipes](../blocks/ClayAndBricks.md#crafting-and-smelting) to re-form a Clay block or smelt balls into [Brick](Brick.md). The guide owns the exact layouts, cooking time, recipe XP, and fuel planning. [Clay crafting][clay-recipe] · [Brick smelting][brick-recipe]

For repeat production, see the checked [Mud-to-Clay setup](../blocks/ClayAndBricks.md#turning-mud-into-clay), then mine its Clay without Silk Touch.
