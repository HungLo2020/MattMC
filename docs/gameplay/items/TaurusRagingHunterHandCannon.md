# Taurus "Raging Hunter" Hand Cannon

Loud, great, and hard on the hands.

## Obtaining

Taurus "Raging Hunter" Hand Cannon can be obtained from the Creative Menu. It is registered as `minecraft:taurus500`.

## Usage

Taurus "Raging Hunter" Hand Cannon is a TaCZ firearm. It uses [.500 Magnum](500Magnum.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
