# Terrapin Spawn Egg

## Obtaining

The Terrapin Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. Use the Terrapin Spawn Egg on a block to spawn a Terrapin.
