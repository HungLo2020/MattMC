# .338 Lapua Bullet

## Obtaining

.338 Lapua Bullet can be obtained from the Creative Menu. It is registered as `minecraft:338`.

## Usage

.338 Lapua Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 30 |
| Used by | [Accuracy International AWM](AccuracyInternationalAWM.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
