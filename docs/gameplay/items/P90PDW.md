# P90 PDW

Draw a smiley face on their body armor.

## Obtaining

P90 PDW can be obtained from the Creative Menu. It is registered as `minecraft:p90`.

## Usage

P90 PDW is a TaCZ firearm. It uses [5.7x28mm AP Bullet](57x28mmAPBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

* 36 blocks: 4.5
* 50 blocks: 4
