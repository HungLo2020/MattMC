# SPAS-12 Multi-purpose Shotgun

We are not going to Ravenholm.

## Obtaining

SPAS-12 Multi-purpose Shotgun can be obtained from the Creative Menu. It is registered as `minecraft:spas_12`.

## Usage

SPAS-12 Multi-purpose Shotgun is a TaCZ firearm. It uses [12 Gauge Bullet](12GaugeBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
