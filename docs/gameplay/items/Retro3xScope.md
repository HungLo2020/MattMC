# Retro 3x Scope

## Obtaining

Retro 3x Scope can be obtained from the Creative Menu. It is registered as `minecraft:scope_retro_2x`.

## Usage

Retro 3x Scope is a TaCZ scope attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Scope |
| Attachment level | Not level-based |
| Compatible guns | [M16A1 Service Rifle](M16A1ServiceRifle.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
