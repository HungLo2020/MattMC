# CZ 75

No limit of shots taken to hit the target.

## Obtaining

CZ 75 can be obtained from the Creative Menu. It is registered as `minecraft:cz75`.

## Usage

CZ 75 is a TaCZ firearm. It uses [9mm Bullet](9mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

| Property | Value |

## Damage Falloff

* 15 blocks: 5
* 35 blocks: 4
* infinite blocks: 3
