# Bee Spawn Egg

## Obtaining

The Bee Spawn Egg is listed in the ordinary Spawn Eggs category. Request it through MattMC's [inventory item browser](../mechanics/InventoryBrowser.md) in **Creative**. See [Spawn eggs](SpawnEggs.md#obtaining) for the shared acquisition rules. [Registration](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/world/item/Items.java#L1802) · [Category entry](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/world/item/CreativeModeTabs.java#L1978)

## Usage

Use the Bee Spawn Egg on a block to spawn a Bee.

## Behavior

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Bee guide](../mobs/Bee.md).
