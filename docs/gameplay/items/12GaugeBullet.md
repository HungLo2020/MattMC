# 12 Gauge Bullet

## Obtaining

12 Gauge Bullet can be obtained from the Creative Menu. It is registered as `minecraft:12g`.

## Usage

12 Gauge Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 36 |
| Used by | [AA12 Shotgun](AA12Shotgun.md), [DB-2 Durin](DB2Durin.md), [DB-4 Ursus](DB4Ursus.md), [M1014 Battle Shotgun](M1014BattleShotgun.md), [M870](M870.md), [SPAS-12 Multi-purpose Shotgun](SPAS12MultipurposeShotgun.md), [Winchester Model 1897](WinchesterModel1897.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
