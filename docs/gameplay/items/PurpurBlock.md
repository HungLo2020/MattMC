# Purpur Block

**Purpur Block** (`minecraft:purpur_block`) is the basic purple construction block used by the Purpur family. [Item registration][items]

## Obtaining and use

Craft it from **Popped Chorus Fruit**, or mine placed Purpur Blocks with an **unbroken pickaxe**, including Wood. Silk Touch is unnecessary; the block drops itself. The [family guide](../blocks/EndStoneAndPurpur.md#obtaining-in-the-end) explains the checked End City route, and [Chorus processing](../blocks/EndStoneAndPurpur.md#chorus-fruit-to-purpur) explains the ingredient chain. [Recipe][crafting-purpur-block] · [Loot][loot-purpur-block] · [Mining tag][pickaxe]

Place it directly or follow the [Purpur recipes](../blocks/EndStoneAndPurpur.md#purpur-variants-and-recipes) for pillars, stairs and slabs. A plain Purpur Block has no pillar axis. Mining it does not return Popped Chorus Fruit. [Registered classes][blocks]

Related: [Popped Chorus Fruit](PoppedChorusFruit.md) · [Purpur Pillar](PurpurPillar.md) · [Items](Items.md)
