# Sniper Ammo Extended Mag II

## Obtaining

Sniper Ammo Extended Mag II can be obtained from the Creative Menu. It is registered as `minecraft:sniper_extended_mag_2`.

## Usage

Sniper Ammo Extended Mag II is a TaCZ extended mag attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Extended Mag |
| Attachment level | 2 |
| Compatible guns | [Accuracy International AWM](AccuracyInternationalAWM.md), [M107 Sniper Rifle](M107SniperRifle.md), [M700 Sniper Rifle](M700SniperRifle.md), [M95 .50 Cal Antimaterial](M9550CalAntimaterial.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

Extended magazine attachments use level 2 to select the corresponding larger magazine size from each compatible gun.

## Notes

* This item is part of the integrated TaCZ firearms system.
