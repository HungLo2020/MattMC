# RPG-7

There's nothing the RPG can't deal... except one more shot!

## Obtaining

RPG-7 can be obtained from the Creative Menu. It is registered as `minecraft:rpg7`.

## Usage

RPG-7 is a TaCZ firearm. It uses [RPG-7 Rocket](RPG7Rocket.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
