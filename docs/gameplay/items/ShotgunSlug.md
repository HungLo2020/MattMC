# Shotgun Slug

## Obtaining

Shotgun Slug can be obtained from the Creative Menu. It is registered as `minecraft:ammo_mod_slug`.

## Usage

Shotgun Slug is a TaCZ ammo modifier attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Ammo Modifier |
| Attachment level | 1 |
| Compatible guns | [AA12 Shotgun](AA12Shotgun.md), [DB-2 Durin](DB2Durin.md), [DB-4 Ursus](DB4Ursus.md), [M1014 Battle Shotgun](M1014BattleShotgun.md), [M870](M870.md), [SPAS-12 Multi-purpose Shotgun](SPAS12MultipurposeShotgun.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
