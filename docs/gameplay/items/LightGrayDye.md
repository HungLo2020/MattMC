# Light Gray Dye

## Obtaining

Light Gray Dye can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Light Gray Dye is used to color blocks, items, entities, and crafting recipes that accept dyes.

## Behavior

Dyes are stackable crafting ingredients.

## Notes

* This item is registered as `minecraft:light_gray_dye`.
