# Wither Spawn Egg

## Obtaining

The Wither Spawn Egg is registered but absent from the checked category list, so it does not appear in the ordinary inventory browser. A player with permission level **2** can obtain it with `/give @s minecraft:wither_spawn_egg`. See [Spawn eggs](SpawnEggs.md#obtaining) for the checked access rules. [Registration](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/world/item/Items.java#L2002) · [Complete category list](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/world/item/CreativeModeTabs.java#L1960-L2128) · [Give permission](https://github.com/HungLo2020/MattMC/blob/aaeea0b263d995334061e562cd5b71a853540f7f/src/main/java/net/minecraft/server/commands/GiveCommand.java#L23-L46)

## Usage

Use the Wither Spawn Egg on a block to spawn a Wither.

## Behavior

See [Spawn eggs](SpawnEggs.md) for block and fluid placement, consumption, spawner changes, supported baby interactions, and Dispenser use. For natural spawning and species behavior, see the [Wither guide](../mobs/Wither.md).
