# Raging Bull

A Taurus Raging Bull hand cannon.

## Obtaining

Raging Bull can be obtained from the Creative Menu. It is registered as `minecraft:trs_bull`.

## Usage

Raging Bull is a TaCZ firearm. It uses [Raging Bull .454 Casull](RagingBull454Casull.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
