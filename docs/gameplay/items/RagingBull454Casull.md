# Raging Bull .454 Casull

## Obtaining

Raging Bull .454 Casull can be obtained from the Creative Menu. It is registered as `minecraft:trs_bull_ammo`.

## Usage

Raging Bull .454 Casull is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 64 |
| Used by | [Raging Bull](RagingBull.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
