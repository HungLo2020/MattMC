# Popped Chorus Fruit

**Popped Chorus Fruit** (`minecraft:popped_chorus_fruit`) is a crafting ingredient. **It is not edible**: unlike raw Chorus Fruit, it has no food/consumable component or eating interaction. [Item registrations][items] · [Item-use dispatch][item-use]

## Obtaining and use

Smelt Chorus Fruit in a Furnace. The [canonical Chorus-to-Purpur section](../blocks/EndStoneAndPurpur.md#chorus-fruit-to-purpur) owns the cooking recipe, timing, experience and checked plant-source route. [Smelting recipe][smelting-popped-chorus-fruit]

Use it to craft Purpur Blocks and [End Rods](EndRod.md). The [Purpur guide](../blocks/EndStoneAndPurpur.md#purpur-variants-and-recipes) covers the construction chain; the End Rod is a separate lighting item. Raw Chorus Fruit is not the named popped ingredient in these recipes. [Purpur recipe][crafting-purpur-block] · [End Rod recipe][end-rod-recipe]

Related: [Chorus Fruit](ChorusFruit.md) · [Purpur Block](PurpurBlock.md) · [Items](Items.md)
