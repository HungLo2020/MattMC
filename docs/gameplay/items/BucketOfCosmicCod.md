# Bucket of Cosmic Cod

## Obtaining

Bucket of Cosmic Cod is obtained by using a Water Bucket on a Cosmic Cod, or from the Creative Menu.

## Usage

Bucket of Cosmic Cod is used to carry and release Cosmic Cod.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:cosmic_cod_bucket`.
