# Bucket of Mimic Octopus

## Obtaining

Bucket of Mimic Octopus is obtained by using a Water Bucket on a Mimic Octopus, or from the Creative Menu.

## Usage

Bucket of Mimic Octopus is used to carry and release Mimic Octopus.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:mimic_octopus_bucket`.
