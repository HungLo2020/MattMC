# UZI

Better than empty hand.

## Obtaining

UZI can be obtained from the Creative Menu. It is registered as `minecraft:uzi`.

## Usage

UZI is a TaCZ firearm. It uses [9mm Bullet](9mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
