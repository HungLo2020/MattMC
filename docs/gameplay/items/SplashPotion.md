# Splash Potion

## Obtaining

Splash Potion can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Splash Potion is a potion item used to apply stored potion effects.

## Behavior

Its use behavior depends on whether it is drinkable, throwable, or splash-based.

## Notes

* This item is registered as `minecraft:splash_potion`.
