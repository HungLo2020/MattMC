# Amber

## Obtaining

Amber can be obtained from the Creative Menu and from any world generation, loot, or recipes enabled for Alex's Caves content in the current build.

## Usage

Amber is a translucent decorative block used for warm fossil, cave, laboratory, and prehistoric builds.

## Behavior

The registered block is transparent, requires the correct tool for drops, and uses glass-like sounds.

## Notes

* This item is the item form of the `minecraft:amber` block.
* Amber is integrated from the bundled Alex's Caves content.
