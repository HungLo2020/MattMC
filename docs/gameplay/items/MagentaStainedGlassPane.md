# Magenta Stained Glass Pane

## Obtaining

Magenta Stained Glass Pane can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Magenta Stained Glass Pane is a thin transparent decorative block for windows and details.

## Behavior

Panes connect to nearby compatible blocks and let light pass through.

## Notes

* This item is the item form of the `minecraft:magenta_stained_glass_pane` block.
