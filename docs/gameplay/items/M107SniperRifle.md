# M107 Sniper Rifle

Destroying them, Politely.

## Obtaining

M107 Sniper Rifle can be obtained from the Creative Menu. It is registered as `minecraft:m107`.

## Usage

M107 Sniper Rifle is a TaCZ firearm. It uses [.50 BMG](50BMG.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
