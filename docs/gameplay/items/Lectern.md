# Lectern

**Lectern** is the placeable item for `minecraft:lectern`, a book-reading stand, redstone source and Librarian job-site block. [Registration][items]

## Obtaining

Use the canonical [Lectern recipe](../blocks/Lectern.md#crafting-placement-and-collection): **4 wooden slabs and 1 ordinary Bookshelf produce 1 Lectern**. Normal mining returns one Lectern without requiring Silk Touch or a tool tier; an axe is faster. Any displayed book drops separately. [Recipe][recipe] · [Block loot][loot] · [Book removal](../blocks/Lectern.md#placing-reading-and-taking-a-book)

## Uses

Place it, then insert a Book and Quill or Written Book to read it. The [block guide](../blocks/Lectern.md) covers book removal, saved pages, comparator strength, page-turn pulses, and the lack of Hopper access to the displayed book. An empty placed Lectern can still be a [Librarian job site](../blocks/Lectern.md#librarian-job-site).
