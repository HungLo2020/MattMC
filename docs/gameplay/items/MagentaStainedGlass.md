# Magenta Stained Glass

## Obtaining

Magenta Stained Glass can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Magenta Stained Glass is a transparent colored building block.

## Behavior

It behaves like glass and lets light pass through while tinting the build visually.

## Notes

* This item is the item form of the `minecraft:magenta_stained_glass` block.
