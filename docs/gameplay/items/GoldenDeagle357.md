# Golden Deagle 357

Shiny and charismatic.

## Obtaining

Golden Deagle 357 can be obtained from the Creative Menu. It is registered as `minecraft:deagle_golden`.

## Usage

Golden Deagle 357 is a TaCZ firearm. It uses [.357 Magnum](357Magnum.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
