# Type 81-1 Service Rifle

Trustworthy.

## Obtaining

Type 81-1 Service Rifle can be obtained from the Creative Menu. It is registered as `minecraft:type_81`.

## Usage

Type 81-1 Service Rifle is a TaCZ firearm. It uses [7.62x39mm Bullet](762x39mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
