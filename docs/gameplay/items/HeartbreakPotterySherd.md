# Heartbreak Pottery Sherd

## Obtaining

Heartbreak Pottery Sherd is found through archaeology sources or obtained from the Creative Menu.

## Usage

Heartbreak Pottery Sherd is used to decorate a Decorated Pot with the heartbreak pattern.

## Behavior

Pottery sherds are crafting ingredients. When used in a Decorated Pot recipe, the sherd determines the pattern on one side of the pot.

## Notes

* This item is registered as `minecraft:heartbreak_pottery_sherd`.
