# Netherite Leggings

## Obtaining

Netherite Leggings can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Netherite Leggings is wearable netherite armor.

## Behavior

It provides armor protection when equipped and has the durability and fire-resistant behavior associated with netherite gear.

## Notes

* This item is registered as `minecraft:netherite_leggings`.
