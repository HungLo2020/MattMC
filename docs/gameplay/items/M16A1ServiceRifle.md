# M16A1 Service Rifle

This is my rifle. There are many like it, but this one is mine.

## Obtaining

M16A1 Service Rifle can be obtained from the Creative Menu. It is registered as `minecraft:m16a1`.

## Usage

M16A1 Service Rifle is a TaCZ firearm. It uses [5.56x45mm Bullet](556x45mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
