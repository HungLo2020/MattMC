# Bucket of Comb Jelly

## Obtaining

Bucket of Comb Jelly is obtained by using a Water Bucket on a Comb Jelly, or from the Creative Menu.

## Usage

Bucket of Comb Jelly is used to carry and release Comb Jelly.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:comb_jelly_bucket`.
