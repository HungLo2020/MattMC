# Iron Ingot

## Obtaining

Iron Ingot can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Iron Ingot is used as a crafting ingredient, dye-related item, or resource item depending on the recipe.

## Behavior

It is a stackable item unless its item properties define a different stack limit.

## Notes

* This item is registered as `minecraft:iron_ingot`.
