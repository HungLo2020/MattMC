# DB-4 Ursus

You can use words and money to solve the problem. Or, just bring it to the table.

## Obtaining

DB-4 Ursus can be obtained from the Creative Menu. It is registered as `minecraft:db_long`.

## Usage

DB-4 Ursus is a TaCZ firearm. It uses [12 Gauge Bullet](12GaugeBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

* 16 blocks: 30
* 24 blocks: 25
* infinite blocks: 15
