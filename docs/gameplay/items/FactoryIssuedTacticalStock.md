# Factory Issued Tactical Stock

## Obtaining

Factory Issued Tactical Stock can be obtained from the Creative Menu. It is registered as `minecraft:oem_stock_tactical`.

## Usage

Factory Issued Tactical Stock is a TaCZ stock attachment. Install it through the gun refit screen on compatible firearms.

## Properties

| Property | Value |
| --- | --- |
| Attachment type | Stock |
| Attachment level | Not level-based |
| Compatible guns | [AKM](AKM.md), [DB-2 Durin](DB2Durin.md), [HK G3 Battle rifle](HKG3Battlerifle.md), [HK-MP5A5](HKMP5A5.md), [RPK](RPK.md), [Vector SMG](VectorSMG.md) |

## Behavior

Attachments can alter gun handling, capacity, sighting, or ballistic behavior depending on their type and the firearm that accepts them.

## Notes

* This item is part of the integrated TaCZ firearms system.
