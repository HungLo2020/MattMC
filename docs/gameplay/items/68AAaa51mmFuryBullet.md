# 6.8A'Aaa51mm Fury Bullet

## Obtaining

6.8A'Aaa51mm Fury Bullet can be obtained from the Creative Menu. It is registered as `minecraft:68x51fury`.

## Usage

6.8A'Aaa51mm Fury Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | No integrated guns currently use this ammo |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
