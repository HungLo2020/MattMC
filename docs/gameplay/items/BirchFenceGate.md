# Birch Fence Gate

## Obtaining

Birch Fence Gate can be obtained from the Creative Menu and by collecting or crafting its block where applicable.

## Usage

Birch Fence Gate is used as an openable passage in fences and walls.

## Behavior

It can be opened by hand or redstone. When closed, it blocks movement; when open, entities can pass through.

## Notes

* This item is the item form of the `minecraft:birch_fence_gate` block.
