# Cyan Harness

## Obtaining

Cyan Harness can be obtained from the Creative Menu and from its normal survival sources when those sources are available.

## Usage

Cyan Harness is used as animal equipment where supported by the current build.

## Behavior

Harness items are color variants and behave as equippable utility items for compatible mobs.

## Notes

* This item is registered as `minecraft:cyan_harness`.
