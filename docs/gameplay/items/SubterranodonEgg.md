# Subterranodon Egg

Subterranodon Egg is the placeable item registered as `minecraft:subterranodon_egg`. Placing it creates a hatchable [egg block](../blocks/SubterranodonEgg.md), rather than immediately spawning a dinosaur.

## Obtaining and use

The item is in the Creative inventory. Its current breeding acquisition path is incomplete, so this page does not promise a renewable Survival source.

Place it on solid ground and protect it from player traffic. Multiple eggs can share a block position, up to four. See the block page for random-tick hatching, nearby-player ownership, and Silk Touch recovery limitations.

For direct Creative placement of the mob, use the separately registered [Subterranodon Spawn Egg](SubterranodonSpawnEgg.md).
