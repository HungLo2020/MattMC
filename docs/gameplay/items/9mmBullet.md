# 9mm Bullet

## Obtaining

9mm Bullet can be obtained from the Creative Menu. It is registered as `minecraft:9mm`.

## Usage

9mm Bullet is ammunition for TaCZ firearms. It is consumed when compatible guns fire in survival unless the player has infinite materials.

## Properties

| Property | Value |
| --- | --- |
| Stack size | 60 |
| Used by | [B93R](B93R.md), [CZ 75](CZ75.md), [Glock 17](Glock17.md), [HK-MP5A5](HKMP5A5.md), [M9A4](M9A4.md), [MP40](MP40.md), [UZI](UZI.md) |

## Behavior

Ammo is counted from the player inventory when reloading compatible firearms. The gun HUD shows both magazine ammo and reserve ammo.

## Notes

* This item is part of the integrated TaCZ firearms system.
