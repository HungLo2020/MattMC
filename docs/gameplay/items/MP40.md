# MP40

Blah blah inspirational movie quote

## Obtaining

MP40 can be obtained from the Creative Menu. It is registered as `minecraft:mp40`.

## Usage

MP40 is a TaCZ firearm. It uses [9mm Bullet](9mmBullet.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.

## Damage Falloff

* 18 blocks: 7
* 40 blocks: 6
* 65 blocks: 5
* infinite blocks: 4
