# Danger Pottery Sherd

## Obtaining

Danger Pottery Sherd is found through archaeology sources or obtained from the Creative Menu.

## Usage

Danger Pottery Sherd is used to decorate a Decorated Pot with the danger pattern.

## Behavior

Pottery sherds are crafting ingredients. When used in a Decorated Pot recipe, the sherd determines the pattern on one side of the pot.

## Notes

* This item is registered as `minecraft:danger_pottery_sherd`.
