# Bucket of Trilocaris

## Obtaining

Bucket of Trilocaris is obtained by using a Water Bucket on a Trilocaris, or from the Creative Menu.

## Usage

Bucket of Trilocaris is used to carry and release Trilocaris.

## Behavior

Using the bucket places the contained creature into water and returns an empty Bucket.

## Notes

* This item is registered as `minecraft:trilocaris_bucket`.
