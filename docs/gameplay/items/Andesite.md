# Andesite

## Obtaining

Andesite is mined underground and can also be obtained from the Creative Menu.

## Usage

Andesite is a gray stone building block. It can be crafted into polished andesite and related building variants.

## Behavior

It behaves like a normal stone block and requires the correct tool for drops.

## Notes

* This item is the item form of the `minecraft:andesite` block.
* It appears in Building Blocks and Natural Blocks.
