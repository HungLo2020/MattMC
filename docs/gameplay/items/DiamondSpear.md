# Diamond Spear

## Obtaining

Diamond Spear can be obtained from the Creative Menu and crafted when its recipe is available.

## Usage

Diamond Spear is a melee thrusting weapon.

## Behavior

Hold use to ready the spear, then release after it is charged to strike targets in front of the user. Spears can be enchanted with Lunge.

## Notes

* This item is registered as `minecraft:diamond_spear`.
