# Ray Gun

Ray Gun from Black Ops 6.

## Obtaining

Ray Gun can be obtained from the Creative Menu. It is registered as `minecraft:raygun_bo6`.

## Usage

Ray Gun is a TaCZ firearm. It uses [Ray Gun Ammo](RayGunAmmo.md) and fires with the TaCZ gun controls. Reload it with the reload key and aim down sights with the aim key.
