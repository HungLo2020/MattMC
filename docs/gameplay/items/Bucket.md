# Bucket

## Obtaining

Buckets are crafted from Iron Ingots and can also be obtained from the Creative Menu.

## Usage

The Bucket is used to pick up, carry, and place fluids or compatible small aquatic mobs.

## Behavior

Using a bucket on compatible fluid sources or entities fills it. Using a filled bucket places or releases its contents.

## Notes

* This item is registered as `minecraft:bucket`.
