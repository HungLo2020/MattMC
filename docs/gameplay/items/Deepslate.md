# Deepslate

**Deepslate** (`minecraft:deepslate`) is the raw, axis-oriented dark building block. It is a different item from Cobbled Deepslate. [Item and block registration][items] [blocks]

## Obtaining and use

Mine Deepslate with an **unbroken Silk Touch pickaxe** to keep this form; an ordinary pickaxe gives Cobbled Deepslate. Smelting Cobbled Deepslate is another way to obtain it. The [Deepslate block guide](../blocks/Deepslate.md#obtaining-and-mining) owns the exact collection and smelting rules. [Loot][loot-deepslate] · [Smelting][smelting-deepslate] · [Mining tag][pickaxe]

The clicked block face determines its axis when placed: see [orienting Deepslate](../blocks/Deepslate.md#orienting-ordinary-deepslate). For polished, brick, tile or chiseled products, use the [Cobbled Deepslate construction chain](../blocks/Deepslate.md#crafting-and-smelting). Ordinary Deepslate is not the input to that polishing recipe. [Axis placement][pillar] · [Polishing recipe][crafting-polished-deepslate]

Related: [Cobbled Deepslate](CobbledDeepslate.md) · [Infested Deepslate rules](../blocks/Deepslate.md#infested-deepslate) · [Items](Items.md)
