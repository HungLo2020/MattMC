# Cave Spider

The **Cave Spider** is an aggressive mob in MattMC.

## Obtaining

Cave Spider can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Cave Spider Spawn Egg](../items/CaveSpiderSpawnEgg.md).

## Behavior

Cave Spider is classified as aggressive here: it is hostile, uses hostile targeting, or has player-targeting behavior in its implementation.

## Notes

* This mob is registered as `minecraft:cave_spider`.
* Its spawn egg is registered as `minecraft:cave_spider_spawn_egg`.
* Its entity registration uses `MobCategory.MONSTER`.
* Its entity class is `CaveSpider`.
* Its registered size is `0.7, 0.5` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
