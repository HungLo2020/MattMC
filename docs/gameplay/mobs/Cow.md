# Cow

The **Cow** is a passive mob in MattMC.

## Obtaining

Cow can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Cow Spawn Egg](../items/CowSpawnEgg.md).

## Behavior

Cow is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:cow`.
* Its spawn egg is registered as `minecraft:cow_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Cow`.
* Its registered size is `0.9, 1.4` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
