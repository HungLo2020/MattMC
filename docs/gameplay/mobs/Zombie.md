# Zombie

The **Zombie** is an aggressive mob in MattMC.

## Obtaining

Zombie can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Zombie Spawn Egg](../items/ZombieSpawnEgg.md).

## Behavior

Zombie is classified as aggressive here: it is hostile, uses hostile targeting, or has player-targeting behavior in its implementation.

## Notes

* This mob is registered as `minecraft:zombie`.
* Its spawn egg is registered as `minecraft:zombie_spawn_egg`.
* Its entity registration uses `MobCategory.MONSTER`.
* Its entity class is `Zombie`.
* Its registered size is `0.6, 1.95` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
