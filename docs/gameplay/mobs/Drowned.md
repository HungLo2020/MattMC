# Drowned

The **Drowned** is an aggressive mob in MattMC.

Drowned can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Drowned Spawn Egg](../items/DrownedSpawnEgg.md).

Drowned is classified as aggressive here: it is hostile, uses hostile targeting, or has player-targeting behavior in its implementation.
