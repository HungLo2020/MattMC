# Squid

The **Squid** is a passive mob in MattMC.

## Obtaining

Squid can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Squid Spawn Egg](../items/SquidSpawnEgg.md).

## Behavior

Squid is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:squid`.
* Its spawn egg is registered as `minecraft:squid_spawn_egg`.
* Its entity registration uses `MobCategory.WATER_CREATURE`.
* Its entity class is `Squid`.
* Its registered size is `0.8, 0.8` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
