# Bat

The **Bat** is a passive mob in MattMC.

## Obtaining

Bat can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Bat Spawn Egg](../items/BatSpawnEgg.md).

## Behavior

Bat is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:bat`.
* Its spawn egg is registered as `minecraft:bat_spawn_egg`.
* Its entity registration uses `MobCategory.AMBIENT`.
* Its entity class is `Bat`.
* Its registered size is `0.5, 0.9` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
