# Cod

The **Cod** is a passive mob in MattMC.

## Obtaining

Cod can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Cod Spawn Egg](../items/CodSpawnEgg.md).

## Behavior

Cod is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:cod`.
* Its spawn egg is registered as `minecraft:cod_spawn_egg`.
* Its entity registration uses `MobCategory.WATER_AMBIENT`.
* Its entity class is `Cod`.
* Its registered size is `0.5, 0.3` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
