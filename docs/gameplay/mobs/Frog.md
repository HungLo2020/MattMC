# Frog

The **Frog** is a passive mob in MattMC.

## Obtaining

Frog can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Frog Spawn Egg](../items/FrogSpawnEgg.md).

## Behavior

Frog is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:frog`.
* Its spawn egg is registered as `minecraft:frog_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Frog`.
* Its registered size is `0.5, 0.5` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
