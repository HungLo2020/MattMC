# Cat

The **Cat** is a passive mob in MattMC.

## Obtaining

Cat can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Cat Spawn Egg](../items/CatSpawnEgg.md).

## Behavior

Cat is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:cat`.
* Its spawn egg is registered as `minecraft:cat_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Cat`.
* Its registered size is `0.6, 0.7` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
