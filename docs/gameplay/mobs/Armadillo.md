# Armadillo

The **Armadillo** is a passive mob in MattMC.

## Obtaining

Armadillo can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Armadillo Spawn Egg](../items/ArmadilloSpawnEgg.md).

## Behavior

Armadillo is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:armadillo`.
* Its spawn egg is registered as `minecraft:armadillo_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Armadillo`.
* Its registered size is `0.7, 0.65` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
