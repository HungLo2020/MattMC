# Turtle

The **Turtle** is a passive mob in MattMC.

## Obtaining

Turtle can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Turtle Spawn Egg](../items/TurtleSpawnEgg.md).

## Behavior

Turtle is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:turtle`.
* Its spawn egg is registered as `minecraft:turtle_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Turtle`.
* Its registered size is `1.2, 0.4` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
