# Axolotl

The **Axolotl** is a passive mob in MattMC.

## Obtaining

Axolotl can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Axolotl Spawn Egg](../items/AxolotlSpawnEgg.md).

## Behavior

Axolotl is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:axolotl`.
* Its spawn egg is registered as `minecraft:axolotl_spawn_egg`.
* Its entity registration uses `MobCategory.AXOLOTLS`.
* Its entity class is `Axolotl`.
* Its registered size is `0.75, 0.42` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
