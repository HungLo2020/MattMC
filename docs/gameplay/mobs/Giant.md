# Giant

The **Giant** is an aggressive mob in MattMC.

## Obtaining

Giant is registered as a mob entity, but it does not have a dedicated spawn egg item in the current item registry. It can be encountered only through commands, data-driven content, or systems that explicitly spawn `minecraft:giant`.

## Behavior

Giant is classified as aggressive here: it is registered in `MobCategory.MONSTER`, is blocked from peaceful difficulty, and uses the hostile mob registration path.

## Notes

* This mob is registered as `minecraft:giant`.
* It does not currently have a registered spawn egg item.
* Its entity registration uses `MobCategory.MONSTER`.
* Its entity class is `Giant`.
* Its registered size is `3.6, 12.0` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
