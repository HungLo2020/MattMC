# Mooshroom

The **Mooshroom** is a passive mob in MattMC.

## Obtaining

Mooshroom can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Mooshroom Spawn Egg](../items/MooshroomSpawnEgg.md).

## Behavior

Mooshroom is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:mooshroom`.
* Its spawn egg is registered as `minecraft:mooshroom_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `MushroomCow`.
* Its registered size is `0.9, 1.4` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
