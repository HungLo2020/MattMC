# Tadpole

The **Tadpole** is a passive mob in MattMC.

## Obtaining

Tadpole can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Tadpole Spawn Egg](../items/TadpoleSpawnEgg.md).

## Behavior

Tadpole is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:tadpole`.
* Its spawn egg is registered as `minecraft:tadpole_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Tadpole`.
* Its registered size is `0.4, 0.3` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
