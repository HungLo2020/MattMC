# Ocelot

The **Ocelot** is a passive mob in MattMC.

## Obtaining

Ocelot can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Ocelot Spawn Egg](../items/OcelotSpawnEgg.md).

## Behavior

Ocelot is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:ocelot`.
* Its spawn egg is registered as `minecraft:ocelot_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Ocelot`.
* Its registered size is `0.6, 0.7` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
