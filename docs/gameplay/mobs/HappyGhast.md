# Happy Ghast

The **Happy Ghast** is a passive mob in MattMC.

## Obtaining

Happy Ghast can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Happy Ghast Spawn Egg](../items/HappyGhastSpawnEgg.md).

## Behavior

Happy Ghast is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:happy_ghast`.
* Its spawn egg is registered as `minecraft:happy_ghast_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `HappyGhast`.
* Its registered size is `4.0, 4.0` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
