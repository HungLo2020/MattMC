# Breeze

The **Breeze** is an aggressive mob in MattMC.

## Obtaining

Breeze can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Breeze Spawn Egg](../items/BreezeSpawnEgg.md).

## Behavior

Breeze is classified as aggressive here: it is hostile, uses hostile targeting, or has player-targeting behavior in its implementation.
