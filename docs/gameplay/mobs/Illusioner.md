# Illusioner

The **Illusioner** is an aggressive mob in MattMC.

## Obtaining

Illusioner is registered as a mob entity, but it does not have a dedicated spawn egg item in the current item registry. It can be encountered only through commands, data-driven content, or systems that explicitly spawn `minecraft:illusioner`.

## Behavior

Illusioner is classified as aggressive here: it is registered in `MobCategory.MONSTER`, is blocked from peaceful difficulty, and uses the hostile mob registration path.

## Notes

* This mob is registered as `minecraft:illusioner`.
* It does not currently have a registered spawn egg item.
* Its entity registration uses `MobCategory.MONSTER`.
* Its entity class is `Illusioner`.
* Its registered size is `0.6, 1.95` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
