# Villager

The **Villager** is a passive mob in MattMC.

## Obtaining

Villager can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Villager Spawn Egg](../items/VillagerSpawnEgg.md).

## Behavior

Villager is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:villager`.
* Its spawn egg is registered as `minecraft:villager_spawn_egg`.
* Its entity registration uses `MobCategory.MISC`.
* Its entity class is `Villager`.
* Its registered size is `0.6, 1.95` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
