# Fox

The **Fox** is a passive mob in MattMC.

## Obtaining

Fox can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Fox Spawn Egg](../items/FoxSpawnEgg.md).

## Behavior

Fox is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:fox`.
* Its spawn egg is registered as `minecraft:fox_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Fox`.
* Its registered size is `0.6, 0.7` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
