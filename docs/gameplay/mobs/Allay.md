# Allay

The **Allay** is a passive mob in MattMC.

## Obtaining

Allay can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Allay Spawn Egg](../items/AllaySpawnEgg.md).

## Behavior

Allay is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:allay`.
* Its spawn egg is registered as `minecraft:allay_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Allay`.
* Its registered size is `0.35, 0.6` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
