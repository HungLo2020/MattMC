# Allay

The **allay** is a flying passive mob that can collect dropped items that match an item it has been given, and then deliver those items to a player or to a note block it has recently heard.

Allays do not normally spawn in the world outside of these structures

## Behavior

An allay can be given an item by interacting with it while holding that item.
After receiving an item, it searches nearby dropped item stacks that match the
held item and carries matching items back to the player or to a recently heard
note block.

## Note block interaction

When an allay hears a note block, it can treat that note block as its delivery
target for a short time. This allows players to build item collection systems
that direct allays toward a specific drop-off point.

## Drops
Upon death, allays drop the item they are holding. Besides this, allays drop no other items or experience.
