# Wandering Trader

The **Wandering Trader** is a passive mob in MattMC.

## Obtaining

Wandering Trader can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Wandering Trader Spawn Egg](../items/WanderingTraderSpawnEgg.md).

## Behavior

Wandering Trader is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:wandering_trader`.
* Its spawn egg is registered as `minecraft:wandering_trader_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `WanderingTrader`.
* Its registered size is `0.6, 1.95` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
