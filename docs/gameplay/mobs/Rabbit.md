# Rabbit

The **Rabbit** is a passive mob in MattMC.

## Obtaining

Rabbit can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Rabbit Spawn Egg](../items/RabbitSpawnEgg.md).

## Behavior

Rabbit is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:rabbit`.
* Its spawn egg is registered as `minecraft:rabbit_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Rabbit`.
* Its registered size is `0.4, 0.5` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
