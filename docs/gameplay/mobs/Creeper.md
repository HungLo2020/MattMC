# Creeper

The **Creeper** is an aggressive mob in MattMC.

## Obtaining

Creeper can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Creeper Spawn Egg](../items/CreeperSpawnEgg.md).

## Behavior

Creeper is classified as aggressive here: it is hostile, uses hostile targeting, or has player-targeting behavior in its implementation.

## Notes

* This mob is registered as `minecraft:creeper`.
* Its spawn egg is registered as `minecraft:creeper_spawn_egg`.
* Its entity registration uses `MobCategory.MONSTER`.
* Its entity class is `Creeper`.
* Its registered size is `0.6, 1.7` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
