# Sniffer

The **Sniffer** is a passive mob in MattMC.

## Obtaining

Sniffer can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Sniffer Spawn Egg](../items/SnifferSpawnEgg.md).

## Behavior

Sniffer is classified as passive here: it does not normally start fights with players. Any special interactions, taming, breeding, bucket, mount, or utility behavior still follows its in-game implementation.

## Notes

* This mob is registered as `minecraft:sniffer`.
* Its spawn egg is registered as `minecraft:sniffer_spawn_egg`.
* Its entity registration uses `MobCategory.CREATURE`.
* Its entity class is `Sniffer`.
* Its registered size is `1.9, 1.75` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
