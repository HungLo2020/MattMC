# Skeleton

The **Skeleton** is an aggressive mob in MattMC.

## Obtaining

Skeleton can be encountered through its normal spawning rules, structures, events, or content-specific systems when those systems are available. For creative testing and mapmaking, use the [Skeleton Spawn Egg](../items/SkeletonSpawnEgg.md).

## Behavior

Skeleton is classified as aggressive here: it is hostile, uses hostile targeting, or has player-targeting behavior in its implementation.

## Notes

* This mob is registered as `minecraft:skeleton`.
* Its spawn egg is registered as `minecraft:skeleton_spawn_egg`.
* Its entity registration uses `MobCategory.MONSTER`.
* Its entity class is `Skeleton`.
* Its registered size is `0.6, 1.99` blocks.
* This mob comes from the base MattMC/Minecraft entity set.
