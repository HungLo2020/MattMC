The project’s primary goal is to incrementally and safely migrate MattMC’s entire rendering pipeline from Java to Rust, including OpenGL, Vulkan, shaders, Distant Horizons, and all rendering callsites. Frozen Java OpenGL (seperate repo) is the authoritative correctness baseline, and Current repo Rust rendering must reproduce its behavior closely; Frozen Java Vulkan is not a valid reference. Frozen may be modified only for deterministic testing, diagnostics, capture, and observability, never to change rendering behavior, and any suspected Frozen bug must be brought to me before proceeding. At the same time, we are designing the ideal explicit Rust architecture: semantic callsites feed an explicit rust implemented VulkanicGAL, Rust Vulkan consumes that state directly, and only the Rust OpenGL backend privately reconstructs OpenGL’s implicit state machine. Parity testing should use the same shared harness across both repositories wherever possible, with explicit repository targeting and equivalent fixtures, camera state, packs, timing, diagnostics, and visual captures. Progress should prioritize expanding real Rust-owned rendering coverage while using rigorous cross-repository parity to catch regressions, not letting validation infrastructure become the project’s main output. it is critical this migression happens incrementally and safely.
