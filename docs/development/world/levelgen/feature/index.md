# Feature generation

Keep each feature's draws, reads and writes in Java's order. Native decoration
runs whole placed features; the older geometry kernels are shared by both routes.

- [Native biome decoration](RUST-DECORATION.md): placed features that run end to end in Rust, their gates and FULL-chunk verification.
  [Recorded results](RUST-DECORATION-RESULTS.md).
- [Rust ore geometry](RUST-ORE.md): ownership, parity checks and placement benchmarks.
- [Rust geode density fields](RUST-GEODE.md): batched numeric evaluation, seed compatibility and verification.

- [End feature computations](RUST-END-FEATURES.md): shared geometry, Java effect boundaries and targeted Frozen verification.

- [Fallen-tree development](RUST-FALLEN-TREES.md): native feature/decorator ownership, live contracts and verification limits.
