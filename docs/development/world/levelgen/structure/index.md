# Structure generation

Structure placement checks and jigsaw start planning run in Rust; other
structure starts still plan in Java. Pieces and template blocks place natively inside the
decoration step loop.

- [Native structure pieces](RUST-STRUCTURE-PIECES.md): piece families, template
  tails, Java steps, placement checks and verification.
- [Native structure templates](RUST-STRUCTURE-TEMPLATES.md): processors, the
  write loop, block-entity replay, gates and structure-region verification.
