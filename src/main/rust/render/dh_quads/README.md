# DH quad owner

Build-local CPU policy for ordinary DH geometry. `mod.rs` owns typed lists,
classification, stable sorting and greedy merging. `packets.rs` owns immutable
layer plans, ordered callback events, shading and final byte encoding;
`column.rs` retains final packets and companions for direct ledger transfer;
`ffi.rs` exposes scoped CPU leases and caller-owned copies. GPU ownership stays
in VulkanicGAL. `faces.rs` owns adjacent visibility/light intervals and semantic
vertical splits, inserting faces directly into this owner. Neighbor CPU windows
are borrowed synchronously; two build-local scratch vectors retain no source
pointer. `boxes.rs` owns complete box geometry, top/bottom visibility, fake-ocean
policy and stock directional shading from bounded CPU facts. Java still traverses
primary sources and supplies world context; custom shade callbacks retain their
compatibility route.
