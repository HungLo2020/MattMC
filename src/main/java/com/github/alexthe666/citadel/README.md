# Citadel Integration

This directory contains the Citadel library integrated from `frnsrc/Citadel-1.21/`.

Citadel provides:
- Advanced entity model system (AdvancedEntityModel, AdvancedModelBox)
- Advanced pathfinding for complex entity movement
- Animation system for entity animations
- Various rendering utilities

This integration is the foundation for AlexsCaves entities like Subteranodon.
